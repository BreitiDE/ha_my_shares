# My Shares

Home-Assistant-App: Aktienliste per WKN mit Empfehlungsindex 0–10 aus mehreren Quellen
(Yahoo Finance, Finnhub, Financial Modeling Prep, Kursziel-Potenzial, Technik).

Installation: In Home Assistant unter **Einstellungen → Apps → App Store → ⋮ → Repositories**
`https://github.com/BreitiDE/ha_my_shares` hinzufügen und „My Shares“ installieren.

Der Index fasst Einschätzungen Dritter zusammen und ist keine Anlageberatung.
